Project 04

EZmap — AI Agent 내비게이션

형태: 3인 팀
담당: 랜드마크 기반 음성 안내 문구 생성(논문 주제) + 내비게이션 기능 개발
AI Agent음성 UX문구 생성 (NLG)Navigation
01

배경 / 문제

도로명이나 정확한 주소를 직접 입력해야 하는 기존 길찾기 방식보다, 사용자가 기억하기 쉬운 POI/Landmark로 목적지를 표현하는 것이 더 자연스러울 수 있다는 문제의식에서 출발했습니다.

02

역할과 책임

랜드마크 기반 음성 안내 문구를 생성하는 로직(본인의 논문 주제)과, 전반적인 내비게이션 기능 개발을 담당했습니다.

[추가 정보 필요 — Agent 전체 아키텍처 중 의도 해석·경로 탐색 부분의 기여 범위. 확인 전까지 이 부분은 본인 성과로 서술하지 않습니다.]
03

아키텍처 / 시스템 구조

User → Voice Input → Intent Understanding → AI Agent
→ POI / Landmark → Route Generation → Voice Navigation
비기술 요약: 사용자가 음성으로 목적지를 랜드마크 이름으로 말하면, Agent가 의도를 해석해 경로를 만들고 음성으로 안내하는 내비게이션입니다.
