배경 / 문제

RTO 설비와 도장/건조 부스의 상태·환경 데이터를 체계적으로 모니터링하고 운영 효율을 높이려면, 설비 상태·VOCs 농도·온습도·유속·전압/전류/전력량 확인, 이상 상태 알람, 원격 제어, 일정 기반 운전, 설비 효율 분석 기능이 필요했습니다.

역할과 책임

  • 사용자 관점의 모니터링 요구사항 정리
  • Siemens SCADA / AVEVA SCADA 사례 참고
  • HMI 화면 구성 설계
  • 센서 및 데이터 항목 정리
  • 모니터링/제어 시스템 기능 구조 설계 및 구현 (단독 수행)

→ 센서 데이터 구조화 → SCADA/HMI 기능 설계 → 원격 제어 / Alarm / Scheduling → 효율 분석
비기술 요약: 현장의 센서 데이터를 한 화면(HMI)에서 확인하고, 필요하면 원격으로 설비를 제어하거나 일정에 따라 자동으로 운전할 수 있게 만든 시스템입니다.
