01

배경 / 문제

기업 내부의 문서와 데이터는 여러 NAS에 분산되어 있고 구조도 통일되어 있지 않습니다. 원본 데이터를 LLM에 무분별하게 전달하면 보안 위험이 발생하고, 접근 권한이 없는 정보가 AI 응답에 포함될 수 있으며, 인프라를 전면 교체하는 방식은 비용 부담이 큽니다.

핵심 질문: "기존 사내 인프라를 유지하면서, 필요한 정보만 안전하게 AI에 전달할 수 있는 구조를 어떻게 만들 것인가?"
02

역할과 책임

  • 전체 시스템 구조 설계 (기획~구현 단독 수행)
  • NAS 데이터 구조 설계 (PARA)
  • MCP 기반 아키텍처 설계
  • 보안 구조 설계 (RBAC, Context Filtering)
  • AI 업무지원 기능 정의 및 Claude 연계 구조 검토
  • 업무 자동화 시나리오 설계
03

아키텍처 / 시스템 구조

사내 NAS → PARA 구조 → Parsing/Indexing → MCP Server
→ RBAC / Context Filtering → Claude / LLM → 업무지원 서비스
비기술 요약: AI가 사내 데이터를 전부 보는 것이 아니라, 사용자가 권한을 가진 범위 안에서 필요한 최소한의 정보만 조회해 LLM에 전달하는 구조입니다.
04

핵심 기능 / 구현 포인트

PARA 데이터 표준화 문서 Parsing/Indexing MCP 연결 계층 RBAC 권한 검증 Context Filtering 자연어 업무 자동화
